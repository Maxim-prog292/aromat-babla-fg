# Собери аромат денег

Автономное веб-приложение для сенсорного киоска.

## Запуск

Откройте `index.html` через локальный веб-сервер или киоск-браузер. Все данные для редактирования находятся в `config.json`.

## Настройка

В `config.json` можно менять:

- тексты экранов;
- список ингредиентов;
- цвета ароматов;
- баллы ингредиентов;
- 3 итоговых результата;
- номера флаконов;
- таймер бездействия;
- длительность смешивания.

Для киоск-режима откройте страницу в полноэкранном браузере с масштабом 100%.
